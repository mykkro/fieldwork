Your page. Your map.

This is an ordinary page embedding Fieldwork with a map-only JSON configuration. Pan and zoom the map below: pressure, wind, stations, and a survey route are configured in embed.json.

Use an iframe wherever your page needs a map. Give it an explicit height. This example works with Flask or a static HTTP server.

<iframe
  src="/index.html?config=examples/embed.json"
  title="Fieldwork map of Prague"
  style="width:100%;height:560px;border:0"
></iframe>

For a viewer hosted elsewhere, use its full URL in src. The configuration path is relative to the viewer page. Map attribution remains visible.
